# UniGlory Energy website

A fast, static marketing website for UniGlory Energy LLC.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build for production

```bash
npm run build
npm run preview
```

The production files are generated in `dist/` and can be deployed to Netlify, Vercel, Cloudflare Pages, GitHub Pages, or any static web host.

## Before launch

- Replace the Unsplash image URLs with licensed company/product photography when available.
- Connect the quote form to a form provider or CRM if you want submissions without opening the visitor's email client.
- Verify the exact warehouse wording, certifications, warranty terms, and product brands before publishing.
- Add Google Search Console and submit `https://www.unigloryenergy.com/sitemap.xml`.
